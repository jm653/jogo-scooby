# Cão Vingador: A Caçada ao Hambúrguer

Jogo 2D desenvolvido em Python com Pygame. Controle o cachorro, colete os hambúrgueres e evite os vilões.

## Requisitos

- Python 3.10 ou superior
- Pygame

## Instalação

No terminal, dentro da pasta do projeto:

```powershell
python -m pip install -r requirements.txt
```

## Execução

```powershell
python scripts/main.py
```

As imagens usadas pelo jogo ficam na pasta `assets/`. As pontuações são armazenadas em `ranking.txt`.

## Controles

- Setas direcionais: movimentar o personagem
- Enter: iniciar ou jogar novamente
- Esc: sair na tela final
